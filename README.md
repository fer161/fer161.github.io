# Antesis — Portafolio de Fernanda Mendiola

Portafolio web de **Fernanda Mendiola Silva**, desarrolladora Full Stack e ingeniera en sistemas computacionales.

🌐 **Sitio:** https://fer161.github.io

## Contenido

- `index.html` — página principal: proyectos, servicios, stack, trayectoria y contacto.
- `lirien.html` — case study de Lirien (app móvil en Flutter + NestJS + PostgreSQL).
- `styles.css` — sistema visual con modo oscuro y claro (variables de color al inicio del archivo).
- `app.js` — interacciones: cambio de tema, menú móvil, filtros, animaciones y formulario de contacto.

## Ver en local

```bash
python3 -m http.server 8080
```

Abrir http://localhost:8080

## Tecnologías

HTML5, CSS3 y JavaScript sin frameworks ni dependencias. Tipografías Geist, Geist Mono e Instrument Serif (Google Fonts).
